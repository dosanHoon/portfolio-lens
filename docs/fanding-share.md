---

### 왜 만들었나

- 계좌·종목이 흩어져 있어서 **전체 그림**이 잘 안 보였고
- **4버킷**(인덱스 / 개별 / 현금 / 크립토) 목표 대비 얼마나 벗어났는지 매번 손으로 계산하기 귀찮았습니다
- 시세 API 없이, **현재가·평단은 직접 입력** — 가볍게 쓰려고 했어요

---

### 스크린샷 1 — 분석 한눈에

- 총 평가액, 평가손익(평단 입력 시)
- **YTD · YOY** — 전년도 말·1년 전 평가액 넣으면 표시
- **4버킷** 한 줄 요약: 목표 대비 과다 / 부족 / 정상 (±5%p)
- 버킷 칸을 누르면 **구성 종목** 모달

---

### 스크린샷 2~3 — 현금 · 종목 · 익스포저

- **현금 관찰선** — 밴드(기본 20~30%) 안에 있는지만. 매매 신호 ❌
- **상위 10종목** — 같은 지수 ETF는 합산 (S&P500, 나스닥100 등)
- **익스포저** — 국장/미장, AI 우산, 반도체 (카드 누르면 근거 종목)

분류 참고: 섹터·테마 ETF, 레버리지는 **개별종목**. 순수 지수 ETF만 **인덱스**.

---

### 스크린샷 4 — 입력

- KRW / USD 종목, 환율, 원화·달러 현금
- **YTD · YOY 기준금액** — 여기 넣어야 히어로·벤치마크에 수익률 나옵니다
- 엑셀 **복사 → 붙여넣기**, JSON 백업 가능
